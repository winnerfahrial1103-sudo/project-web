# Camilla Store — Payment Page

Website payment page bertema **cute soft pink** untuk **Camilla Store** lengkap dengan **Admin Panel** agar pemilik toko bisa mengubah nomor rekening/e-wallet, upload gambar QRIS, dan memperbarui status/informasi limit kapan saja.

## Metode Pembayaran Default
1. **DANA** (E-Wallet)
2. **GoPay** (E-Wallet)
3. **ShopeePay (SPay)** (E-Wallet)
4. **QRIS 1 (Utama)** (QRIS)
5. **QRIS 2 (Cadangan)** (QRIS)

## Cara Menjalankan
Pastikan Node.js (>= 20) sudah terpasang, lalu jalankan di folder proyek:

```bash
npm start
```

- Halaman Customer: `http://localhost:3456/`
- Halaman Admin: `http://localhost:3456/admin`
- Password Admin awal: `camilla123` (segera ganti lewat tombol **Ganti Password** setelah login!)

## Menjalankan Tes
```bash
npm test
```
